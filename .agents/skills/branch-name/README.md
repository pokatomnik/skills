## What is this?

This project generates concise git branch names from a project purpose and a git diff. it keeps versioning clear and intuitive

## What is is this project for?

Useful for developers who need quick meaningful branch naming without guesswork

## Usage

Copy and paste this skill text or use in you favorite agent (do not forget to replace placeholders inside with the files you need to be documented)

it will output `feature/branch_name`. 🎈
